# Staged FOD Capture: Ramp Checklist (pilot, 1 Gate)

For the ticket "Capture a pilot set of staged FOD images from our gate cameras". Allow about 60–90 minutes with an empty stand, or a parked narrowbody during a long ground time. Daylight first; one dusk or night repeat if possible.

## Before you go
- [ ] Get ramp access approval and a safety escort. Coordinate with the airport ops / FOD manager (the airport owns the FOD program).
- [ ] Get camera access: the ability to save a full-resolution still from each gate camera (not a screenshot of the viewer).
- [ ] Build the **test-object kit**, based on FAA AC 150/5220-24 and AC 150/5210-24A. Number every item and tag it with high-visibility tape on a side the cameras can't see:
  - [ ] metal cylinder about 1.2 in × 1.5 in diameter
  - [ ] golf ball (1.7 in)
  - [ ] wrench (≤8 in)
  - [ ] socket (≥2 in)
  - [ ] lug nut and a few bolts/washers
  - [ ] fuel cap
  - [ ] strip of tyre rubber
  - [ ] bent metal strip (≤8 in)
  - [ ] luggage wheel or zipper pull
  - [ ] bag tag
  - [ ] soda can
  - [ ] plastic wrap / strapping
  - [ ] concrete or asphalt chunk
- [ ] Bring a clipboard or tablet with the log sheet below, a tape measure, and a phone for reference photos.

## 1. Record the camera layout (once)
For each physical camera: ID, mount (jet bridge / terminal wall / pole / other), height, fixed or pan-tilt, resolution, file format, typical file size.
Then fill in the **Angle coverage** table. Which camera, and which part of its frame, shows each zone?

| Angle | Zone it must cover | Camera ID | Region of frame (whole / which part) | Coverage (full / partial / none) |
|---|---|---|---|---|
| NOSE | ahead of the nose, nose gear, pushback path | | | |
| ENG-L | left engine intake area, under the left wing | | | |
| ENG-R | right engine intake area, under the right wing | | | |
| CARGO | right side: cargo doors, belt loader, bag carts | | | |
| AFT | main gear, tail, area behind the aircraft | | | |
| WIDE | whole stand from above | | | |

## 2. Capture sequence (repeat per scenario)
1. [ ] **CLEAN**: stand swept and walked. Save one still from every camera. Label: `G<gate>_S<scenario>_CLEAN_<camera>.jpg`
2. [ ] **PLACE**: place 3–6 kit items across different zones (always include at least one small item: the cylinder, a lug nut or a bolt). Then:
   - [ ] log each item on the sheet below
   - [ ] take a phone photo of each item in place, with a visible landmark
   - [ ] save one still from every camera. Label: `..._FOD_<camera>.jpg`
3. [ ] **CLEARED**: remove all items, check the kit count, and save stills again. Label: `..._CLEARED_<camera>.jpg`

Run **at least 5 scenarios**:

| # | Scenario |
|---|---|
| S1 | Large items, open areas (wrench, fuel cap, can) |
| S2 | Small metal (cylinder, lug nut, bolts) near the engine intake zones |
| S3 | Cargo hotspot: items at the conveyor ends and between bag cart and belt |
| S4 | Normal clutter, no FOD: chocks, cones, GSE and tow bar in place (to measure false alarms) |
| S5 | Hard cases: dark items on dark or wet pavement, items partly in shadow or under the wing |
| S6 (optional) | S2 repeated at dusk or night under ramp lighting |

| Scenario | Item # | Item | Zone / Angle | Position (e.g. "1 m ahead of ENG-L intake lip") | Visible in which cameras | Notes (shadow, wet, partly hidden) |
|---|---|---|---|---|---|---|
| | | | | | | |

## 4. Hand-back
- [ ] Put all stills and phone photos, the log sheet and the camera layout table into one folder.
- [ ] Do a final kit count, sign it off, and confirm the stand is clear.
- [ ] Report back: number of images, resolution and format, any Angle with no coverage, and any surprises (glare, blocked views, low light).
